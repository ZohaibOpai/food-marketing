## ✨ Features

| Feature | Description |
|---|---|
| 🔍 Search Bar | Search food by name in real time |
| 🏷️ Category Filter | Filter by All, Fast Food, Pakistani, Dessert, Drinks |
| 🛒 Cart System | Add items, see total, remove items |
| ✅ Checkout | Place order and clear cart |
| 📬 Contact Form | Send a message with success notification |
| 🍞 Toast Notification | Popup message when item is added |

---

## 🧠 JavaScript Logic Used

- `renderFoods()` — Displays food cards on the page
- `filterCategory()` — Filters food by category
- `filterFood()` — Filters food by search input
- `addToCart()` — Adds item to cart array
- `removeFromCart()` — Removes item from cart
- `updateCartUI()` — Updates cart display and total price
- `toggleCart()` — Opens and closes cart sidebar
- `checkout()` — Clears cart and shows success message
- `submitForm()` — Handles contact form submission
- `showToast()` — Shows popup notification
